# 微信朋友圈点赞助手 v1.18

后台自动给新朋友圈点赞，也可以选择好友和日期范围，为过去的可见朋友圈补赞。

这是独立的朋友圈点赞程序，不包含 AI 自动回复、私聊收发和店铺问答。无需安装 Python，无需 API Key 或付费授权。

## 下载哪个文件

普通用户下载 **`wechat-moments-monitor-v1.18-windows-x64.zip`**，完整解压后运行 `MomentsMonitor` 文件夹中的 `朋友圈后台监控助手.exe`。

`wechat-moments-monitor-v1.18-source.zip` 是源码，供开发者查看和构建。

## 可以做什么

- 监控所有好友的新朋友圈，按随机延迟自动点赞。
- 为指定好友补赞，支持最近一年、全部可见和自定义日期。
- 默认随机等待 1～120 分钟，可自行调整。
- 开始时补查最近 24 小时，也可调整范围。
- 保留未完成计划，已点赞的跳过。
- 显示今日和累计点赞数，以及发布、检测、计划和成功确认时间。
- 后台运行，不截图、不切窗口、不占用鼠标键盘。

## 本次更新

- 精简界面文字，改用更直接的按钮和状态说明。
- 监控时也可以读取、搜索和选择好友。
- 点击“暂停监控并预览”即可切换任务，无需先手动暂停。
- 好友读取失败不再中断监控。

## 使用条件

需要 Windows 64 位和已登录的微信 **4.2.0.9**，程序同时校验微信文件。先在电脑版打开过朋友圈，再启动助手。

电脑、微信和助手需要保持运行。当前版本已在开发者自己的电脑验证，其他电脑的兼容性仍待进一步验证。

程序使用非官方接口，微信升级后可能需要重新适配。发布包不包含个人微信数据；使用后生成的 `data` 文件夹仅供本人保留，不要随程序分享。
