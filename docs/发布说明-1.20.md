# 微信朋友圈点赞助手 v1.20

适配 Windows 微信 **4.2.0.53**。

## 本次更新

- 更新朋友圈后台刷新、同步、指定好友分页和点赞接口适配。
- 核对新版回调初始化结构和调用序号。
- 沿用随机等待、历史补赞、去重和任务记录功能。

## 下载与升级

下载 **`wechat-moments-monitor-v1.20-windows-x64.zip`**，完整解压后运行 `MomentsMonitor` 文件夹内的 `朋友圈后台监控助手.exe`。

升级时先关闭旧助手，将旧程序旁的 `data` 文件夹复制到新程序旁。这样可以保留设置、点赞记录和未完成计划。复制前保留一份旧目录作为备份。

需要 Windows 64 位和已登录的微信 4.2.0.53。程序同时校验微信文件。

微信 4.2.0.13 用户可以继续下载历史版本 v1.19，微信 4.2.0.9 用户可使用 v1.18。

源码包为 `wechat-moments-monitor-v1.20-source.zip`。更多使用步骤见仓库首页。
