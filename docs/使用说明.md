# 朋友圈点赞助手 1.20

## 四个页面

- **总览**：运行状态、最近检查、今日/累计点赞、等待和重试任务，以及成功动效。
- **任务记录**：按好友、处理状态或日期筛选，查看发布时间、首次检测时间、原计划与确认时间。
- **指定好友补赞**：选择一个好友与发布时间范围，先预览朋友圈，再启动独立补赞。
- **设置**：账号、随机等待范围、启动补查小时数、不点赞名单和检查间隔。

## 计划规则

默认新计划随机等待1～120分钟，可改为1～1440分钟。最短与最长相同则固定等待。修改设置只影响新计划，已有计划保持原时间。

关闭期间不执行；重新运行后保留去重记录并继续到期任务。仅监控模式只记录，点击开始自动点赞后才处理计划。启动补查默认24小时，可设1～168小时，或关闭补查。

指定好友补赞只处理本次好友与日期范围的任务，已有待办会沿用原计划时间。日期范围按发帖时间判断；自定义结束日期包含当天。重启后点击“继续补赞”。

监控时也可以读取、搜索和选择好友。点击“暂停监控并预览”会先结束当前监控任务，再读取所选好友的朋友圈；预览后可开始补赞。需要继续监控所有好友时，点击顶部“开始监控”。

原有点赞、已确认成功、已提交但结果尚未确认的帖子不会自动重复点赞。暂时取不到的旧动态保留计划等待重试，不据此判断对方删除了内容。

## 遇到问题

版本不匹配：确认微信版本与 README 的适配版本一致；程序不支持强制绕过版本校验。

好友同名：下拉列表会分别列出，选择前确认昵称；更改唯一备注名更便于辨认。

扫描没有记录：这不等于好友从未发过朋友圈。保留提示，确认对方对你的账号可见后重试；未确认的空首页不会标记为完成。

结果待核对：到微信查看原动态；程序保留记录，不会自动重复提交。

程序需要电脑、微信和助手保持运行。可最小化继续使用电脑。分享代码和程序时使用干净构建产物，不携带自己的 `data`。
