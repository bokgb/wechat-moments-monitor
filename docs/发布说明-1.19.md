# 微信朋友圈点赞助手 v1.19

适配 Windows 微信 **4.2.0.13**。

## 本次更新

- 更新后台朋友圈刷新、指定好友分页、同步和点赞接口适配。
- 修复新版微信联系人读取失败的问题。
- 保留随机等待、历史补赞、去重记录和四个页面的操作方式。

## 下载与使用

下载 **`wechat-moments-monitor-v1.19-windows-x64.zip`**，完整解压后运行 `MomentsMonitor` 文件夹内的 `朋友圈后台监控助手.exe`。

升级时先关闭旧助手，将旧程序旁的 `data` 文件夹复制到新程序旁，再启动新程序。这样可以保留设置、点赞记录和未完成计划。复制前保留一份旧目录作为备份。

需要 Windows 64 位和已登录的微信 4.2.0.13。程序同时校验微信文件。微信 4.2.0.9 用户可以继续下载历史版本 v1.18。

源码包为 `wechat-moments-monitor-v1.19-source.zip`。功能和使用步骤见仓库首页。
